# **App Name**: TablaTime

## Core Features:

- Carton Generation: Generate random 'cartones' (game boards) with a wooden style for an authentic look.
- Ficha Marking: Automatically or manually mark called 'fichas' on the 'cartones'.
- Card Drawing Emulation: Emulate the roll of the Lotería cards. Option to select game type (line or full board)
- Game Reset: A 'restart game' button is available at all times.
- AI Caller: AI caller tool with traditional verses to read aloud 'fichas' in single-player mode.
- Language Toggle: Switch between English and Spanish language support.

## Style Guidelines:

- Primary color: Saturated yellow (#FFC107) to evoke the warmth and tradition of Lotería.
- Background color: Light beige (#F5F5DC) to simulate the color of the wood of the cards.
- Accent color: Burnt orange (#D2691E) for interactive elements.
- Font: 'Literata', serif, for an elegant, literary feel, applied to both headlines and body text.
- Use traditional Lotería artwork images and elements, simplified into icons where possible.
- Employ large tappable 'cartones' and clearly animated 'fichas'.
- A celebratory confetti animation and sound effect is triggered when the player wins.
